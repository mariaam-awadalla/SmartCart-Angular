# SmartCart

A modern e-commerce web application built with Angular, designed to provide a seamless online shopping experience. The platform includes authentication, product browsing, shopping cart management, wishlist functionality, order tracking, and payment integration.

## Features

- User Registration & Login
- JWT Authentication & Authorization
- Password Recovery & Reset Workflow
- Product Catalog Browsing
- Product Search
- Category & Brand Filtering
- Product Details Page
- Shopping Cart Management
- Wishlist Management
- Order Tracking
- Cash on Delivery Orders
- Online Payment Integration
- Responsive Design
- Route Guards
- HTTP Interceptors
- Loading Indicators
- Toast Notifications
- Custom Validation
- Lazy Loading
- Reusable Components

## Installation

Clone the repository:


Navigate to the project folder:

```bash
cd shopsphere-angular
```

Install dependencies:

```bash
npm install
```

Run the application:

```bash
ng serve
```

Open:

```text
http://localhost:4200
```
